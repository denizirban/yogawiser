# Yogawiser Atlas — prototype 001

Static, zero-build prototype for the Yogawiser Atlas index page.

## Files
- `index.html` — page structure
- `styles.css` — responsive split-screen design
- `script.js` — atlas data, hover/click selection and search
- `assets/` — first 10 project images

## Preview locally
Open `index.html` in a browser, or run any static file server in this folder.

## Vercel
This folder can be deployed as a static site directly. No build step is required for this prototype.
